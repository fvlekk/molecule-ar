# Molecule Lab AR

Web AR for the Topic 9 presentation: scan the QR code, point the phone at it, molecules come out of the code and react (2 H2 + O2 -> 2 H2O, then a hydrogen-bond ring).

- Image tracking: MindAR 1.2.5 (vendored in /lib), three.js 0.160
- Target: target.png -> targets.mind
- Must be served over HTTPS (GitHub Pages is fine). Expected URL: https://fvlekk.github.io/molecule-ar/
